# Репетиция деплоя проекта 

Данный репозиторий содержит инфраструктурную часть проекта — конфигурацию Docker, Nginx и скрипты для развертывания.

## 1. Схема архитектуры проекта
Приложение состоит из трех сервисов, запускаемых в Docker:
*   **Nginx (порт 80, 443)** — единая точка входа, обратный прокси-сервер. Обрабатывает HTTPS.
*   **Frontend (React)** — доступен только внутри сети Docker.
*   **Backend (Node.js + Express)** — доступен только внутри сети Docker. Обращается к базе данных.
*   **PostgreSQL** — база данных, запущенная на хост-машине (вне Docker).

## 2. Таблица сервисов
| Название сервиса | Технология        | Внутренний порт | Продакшен-сервер        |

|      nginx       |      Nginx        |      80, 443    |   - (веб-сервер)        |
|    frontend      |   React, Vite     |      80         | Nginx (раздает статику) |
|     backend      |  Node.js, Express |        3001     |         Node.js         |
|       db         |   PostgreSQL      |     5432        |         локально        |

## 3. Переменные окружения и секреты
*Список переменных, необходимых для работы (значения хранятся в `.env` файле бэкенда):*
- `DB_HOST` — адрес базы данных
- `DB_PORT` — порт базы данных
- `DB_USER` — имя пользователя БД
- `DB_PASSWORD` — пароль БД (секрет)
- `DB_NAME` — имя базы данных
- `PORT` — порт для бэкенда
- `VITE_API_URL` — адрес API для фронтенда (передается при сборке)
